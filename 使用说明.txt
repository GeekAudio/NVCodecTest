GPU-Z — 视频编解码诊断 v1.6.0
=====================================================

用于检查 NullMoth 驱动和 NVIDIA 显卡的 H.264 / HEVC 硬件编解码能力。
采用 Apple 官方 API；本程序是诊断工具，不是官方认证跑分。
测量独立运行，界面进程保存日志及驱动错误；结果仅覆盖实际完成的配置。

安装
----
1. 打开 DMG，把 GPU-Z.app 拖到“应用程序”。
2. 首次双击若被系统拦截，点“完成”关闭提示。
3. 打开“系统设置 › 隐私与安全性 › 安全性”，点“仍要打开”。
4. 输入登录密码，再点“打开”。以后直接双击即可。
5. 从旧版升级时，确认 GPU-Z 能正常打开后，可删除“应用程序”里的旧 NVCodecTest.app；本机诊断记录会保留。

使用
----
程序会在后台采集环境，完成后点“开始测试”。
软件 HEVC 编码较慢，完整测试可能需要几分钟。
外观和强调色跟随 macOS，默认窗口 860 × 670，最小 840 × 660。
主窗口为一个页面，不滚动、不分页：九宫格测试卡片、环境摘要、
NVIDIA 证据结论、进度和所有操作均直接可见。
卡片显示模式、FPS、状态、帧数或错误码；用时和完整统计在详情中，顶部按格式统计通过率。
右侧“完整环境与编码器…”打开详细安装、加载、版本和注册证据。
底部“测量方法”和“日志与反馈”分别打开详情弹窗；详情内容允许滚动。
Command-Return 开始测试，Command-. 请求安全取消。
v1.6.0 保留九宫格和右侧环境摘要。卡片左上角可逐项勾选，支持“全选”“取消全选”和按类型选择；“开始测试”运行勾选的项目。点击卡片后用下方“单独测试”，或右键选“单独测试此项”，只运行这一项。每轮独立记录结果，报告与进度按本轮选择统计；单跑解码时用软件准备输入素材，不额外计为编码测试。软件 HEVC 素材准备可能需要一些时间。底部的 GitHub 链接可打开源码与版本页面。

启动时检查 GitHub 正式新版，可选择更新、跳过该版本或稍后处理。下载显示实际进度，校验后安装并重启。GPU-Z 菜单的“检查更新…”可手动重试；测试过程中不开始安装。自动更新要求应用位于可写的“应用程序”目录。

“测试历史”从本机已有诊断日志读取测试轮次，可选择一轮作为基准，并列查看本轮与历史 FPS。仅相同项目、负载和已确认设备计算变化；其他情况会标明不可比较的原因。历史沿用日志的最近 20 条、30 天、20 MiB 保留范围，不联网回传。

每项结果的“证据与详情”会显示硬件属性、编码器身份、GPU 证据、
完整帧数、重复范围和错误。可以复制详情，也可导出 TXT / JSON。
先选中测试卡片，再点下方“证据与详情…”。同负载有软件结果时，
会显示硬件 / 软件吞吐倍数；它不代表同画质或所有真实视频的性能。
未测试时可先导出环境；取消后可导出已完成部分。
“刷新环境”会清空本轮结果。测试报告使用本轮开始时的环境快照。

日志与反馈
----------
环境诊断和完整测试会自动保存脱敏日志，包括测试阶段、错误、取消状态、
驱动证据、驱动错误输出和完整结果。异常退出后，下次打开会把未结束的记录标为中断。
日志最多保留最近 20 次、30 天，总量最多 20 MiB，可在软件里删除。

点窗口底部“日志与反馈”，选一轮记录，写下遇到的现象，检查脱敏预览。
可以先点“删减日志副本”，去掉不想公开的部分，再检查网页草稿预览。
点“前往 GitHub 确认”会打开 GeekAudio/NVCodecTest 的公开 Issue 草稿，
打开网页会把预览的草稿传给 GitHub 用于预填，尚未创建 Issue。
请用自己的 GitHub 账号登录，再确认提交。
内容太长时，按提示复制草稿或导出日志，在网页粘贴或添加附件。
软件不需要 Token，也不会后台自动回传。

网页反馈默认带上机型、CPU、内存、GPU、系统及驱动版本、本轮结果和错误摘要。
机型是系统报告的 SMBIOS 名称，黑苹果可能自行配置，不含序列号。
自动留存的 boot-args 只保留白名单诊断开关，并移除用户路径及常见身份信息，
保留接口返回，便于排查“硬解通过但 GPU 未确认”。
脱敏不能保证识别所有自定义内容，请提交前再检查。普通“导出报告”保留
完整诊断内容；给开发者反馈时请用“日志与反馈”里的脱敏版本。

怎么看结论
----------
NVIDIA 已证实：完整输出、硬件属性及 NVIDIA 身份证据共同成立。
  NVMTL 编码器身份属于驱动自报，证据来源会在详情说明。
系统硬件 · GPU 未确认：硬件测试已通过，但 API 未提供足够设备身份。
  这不等于硬解失败、显卡不支持或驱动未安装。
其他 GPU / 软件对照：单独标注，不作为 NVIDIA 成功。
失败 / 未验证 / 未测试 / 已取消：原因分别保留，不混为一个“不可用”。

成功仅覆盖本项格式、分辨率与配置；不能外推到所有 profile 或位深。
驱动状态综合加载、注册、组件和版本标记，缺一个版本文件不会报未安装。
磁盘版本与当前加载版本会分别说明，新版本可能需要重启后才生效。

取消
----
点“取消测试”后停止新帧提交，并安全排空已提交帧。
底层驱动调用需要等待返回，所以取消不保证立即完成。
退出应用也会先请求取消并等待当前会话安全结束。
完成的结果会保留，未开始项目明确标为未测试。

怎么看 FPS
----------
编码和解码均预热后测三次，取中位 FPS 对应的完整测量，附重复范围。
只有有效输出全部帧、无丢帧和错误才算通过。
输入是可复现的合成图案，FPS 包含提交、驱动、回调与排空开销。
同码率不等于同画质；倍数只适用于本负载，不能代表所有真实视频。
本程序不评估画质、功耗或长期稳定性，也不能与 NVIDIA 原生性能表横比。
旧版 v1.0 测法不同，请重新测试，不要直接混比分数。
详细方法与官方资料见“测试方法.md”。

命令行
------
环境诊断：
/Applications/GPU-Z.app/Contents/MacOS/NVCodecTest --diagnose --output /tmp/nvcodec-env.json

完整测试（Ctrl-C 请求安全取消）：
/Applications/GPU-Z.app/Contents/MacOS/NVCodecTest --selftest --output /tmp/nvcodec-test.txt --json-output /tmp/nvcodec-test.json

真实窗口重放已有报告（不重新测 GPU）：
/Applications/GPU-Z.app/Contents/MacOS/NVCodecTest --preview --results-json /tmp/nvcodec-test.json

权限与卸载
----------
无需 root，不改 EFI 或系统配置，不安装驱动或后台服务。
会创建临时探测输出、用户导出的报告和本机脱敏诊断日志。
日志位置：~/Library/Application Support/NVCodecTest/Diagnostics。应用保留原 bundle identifier 和日志目录，方便 GPU-Z 继续读取升级前保存的诊断记录。
卸载时可先在“日志与反馈”清空记录，再把 App 拖到废纸篓。许可：MIT。

检测依据
--------
规则按 NullMoth v2.6.2 / 6e37546 和 Apple VideoToolbox API 核对。
完整环境里分别记录 PCI GPU profile、视频注册开关、视频库载入与组件磁盘存在情况。
源码覆盖、合成规则检查与实体显卡实测分开，不能把单台样本结果推广到全部机型。
详见同目录《源码对齐与验证范围.md》。
